Copy the sample config to `config.json`, then put your token in `config.json`.

Add user IDs that can run commands:
`"commandUsers": ["123456789012345678"]`

Windows CMD:
`start.bat`

Android Termux:
`pkg install nodejs`
`sh start.sh`

Any terminal:
`npm start`
