# selfbot

Created and developed by:
- akashsuu

Copy the sample config to `config.json`, then put your token in `config.json`.

Add user IDs that can run commands:
`"commandUsers": ["123456789012345678"]`

Windows CMD:
`start.bat`

Android Termux:
`pkg install nodejs`
`cd ~`
`cp -r /storage/emulated/0/Download/selfbot ~/selfbot`
`cd ~/selfbot`
`rm -rf node_modules`
`npm install --no-bin-links`
`sh start.sh`

Any terminal:
`npm start`
